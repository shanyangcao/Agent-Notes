### 1. `invoke()` — 一次性完整调用

- **核心特点**：同步阻塞式调用，模型生成完整结果后**一次性返回**。
- **返回形式**：直接得到最终文本 / 结构化结果，无需额外处理。
- **适用场景**：


- - 不需要实时预览的场景（如批量数据处理、脚本任务）
  - 追求代码简洁、无需流式交互的场景


- **示例代码**：python运行

```
response = llm.invoke("用Python输出1-10的数字")
print(response)  # 直接打印完整结果
```

### 2. `stream()` — 流式分段输出

- **核心特点**：实时迭代式调用，模型生成内容时**逐段推送**。
- **返回形式**：返回一个可迭代对象，需循环遍历获取每一段内容。
- **适用场景**：


- - 对话交互（如聊天机器人），需要模拟 “打字机” 效果
  - 长文本生成，避免用户等待完整结果
  - 低延迟交互场景


- **示例代码**：python运行

```
for chunk in llm.stream("用Python输出1-10的数字"):
    print(chunk, end="", flush=True)  # 逐段打印，实时刷新
```

### 核心对比

| **方法** | **响应方式**   | **延迟表现** | **代码复杂度** | **适用场景**                   |
| -------- | -------------- | ------------ | -------------- | ------------------------------ |
| `invoke` | 一次性完整返回 | 较高         | 低             | 批量处理、脚本、非交互场景     |
| `stream` | 逐段流式推送   | 低           | 中             | 对话交互、长文本生成、实时场景 |
