```
# 1. 安装依赖（首次运行需要）
# pip install langchain langchain-community dashscope

# 2. 导入核心模块
from langchain_core.runnables import RunnablePassthrough
from langchain_core.prompts import PromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_community.vectorstores import InMemoryVectorStore
from langchain_community.embeddings.dashscope import DashScopeEmbeddings
from langchain_community.chat_models import QianfanChatEndpoint  # 用百度千帆举例（可替换为GPT/通义）
from langchain_core.documents import Document

# 3. 初始化关键组件（补全代码中缺失的部分）
# 初始化嵌入模型（阿里云通义）
embedding = DashScopeEmbeddings(model="text-embedding-v4", dashscope_api_key="你的通义API Key")
# 初始化大模型（百度千帆）
model = QianfanChatEndpoint(model="ERNIE-4.0", qianfan_ak="你的千帆AK", qianfan_sk="你的千帆SK")
# 初始化Prompt模板
prompt = PromptTemplate(
    template="基于以下参考资料回答问题：\n参考资料：{context}\n问题：{input}\n请用简洁的语言回答。",
    input_variables=["context", "input"]
)

# 4. 核心业务代码（你提供的部分）
# 初始化内存向量库
vector_store = InMemoryVectorStore(embedding=embedding)
# 向向量库添加减肥相关文本
vector_store.add_texts([
    "减肥就是要少吃多练",
    "在减脂期间吃东西很重要,清淡少油控制卡路里摄入并运动起来",
    "跑步是很好的运动哦"
])
# 构建检索器（返回最相似的2条）
retriever = vector_store.as_retriever(search_kwargs={"k": 2})

# 定义文档格式化函数
def format_func(docs: list[Document]):
    if not docs:
        return "无相关参考资料"
    formatted_str = "["
    for doc in docs:
        formatted_str += doc.page_content
    formatted_str += "]"
    return formatted_str

# 构建RAG链
chain = (
    {"input": RunnablePassthrough(), "context": retriever | format_func}
    | prompt
    | model
    | StrOutputParser()
)

# 5. 触发执行（用户提问）
input_text = "怎么减肥？"
final_answer = chain.invoke(input_text)
print("最终回答：", final_answer)
```

### 一、代码整体功能

这段代码是一个**基于 LangChain 实现的 RAG（检索增强生成）问答链**，核心是：

1. 把减肥相关知识存入**内存****向量库**
2. 用户提问「怎么减肥？」时，先从向量库检索**最相关的 2 条资料**
3. 把检索到的资料格式化后，和问题一起喂给大模型生成回答

### 二、逐段拆解

#### 初始化向量存储与嵌入模型

```
//向量存储
vector_store = InMemoryVectorStore(embedding=DashScopeEmbeddings(model="text-embedding-v4"))
```

- `InMemoryVectorStore`：内存版向量数据库，数据只存在内存中，适合调试 / 轻量场景
- `DashScopeEmbeddings`：阿里云通义千问的文本嵌入模型，把文本转成向量用于语义检索

#### 向向量库添加资料

```
vector_store.add_texts(["减肥就是要少吃多练", "在减脂期间吃东西很重要,清淡少油控制卡路里摄入并运动起来", "跑步是很好的运动哦"])
```

- `add_texts()`：接收一个字符串列表，把每段文本转成向量并存入向量库
- 这里我们存入了 3 条减肥相关的知识点

#### 构建检索器（Retriever）

```
retriever = vector_store.as_retriever(search_kwargs={"k": 2})
```

- `as_retriever()`：把向量库对象转成可直接接入 LangChain 链的检索器
- `search_kwargs={"k": 2}`：设置检索时返回**最相似的前 2 条结果**

#### 定义格式化函数

```
def format_func(docs: list[Document]):if not docs:return "无相关参考资料"
    formatted_str = "["for doc in docs:
        formatted_str += doc.page_content
    formatted_str += "]"return formatted_str
```

- 输入：检索器返回的 `Document` 列表（每条包含 `page_content` 文本内容）
- 输出：把所有文档内容拼接成 `[内容1内容2]` 格式的字符串（注意：这里格式不标准，更推荐用逗号 + 引号包裹成 JSON 数组）
- 作用：把检索到的文档整理成 Prompt 能识别的上下文格式

#### 构建完整 RAG 链

```
chain = ({"input": RunnablePassthrough(), "context": retriever | format_func} 
    | prompt 
    | model 
    | StrOutputParser())
```

- [讲解chain = ({"input": RunnablePassthrough(), "context": retriever | format_func} ](https://www.yuque.com/yuqueyonghu-eoouks/oxranl/bkk3785k47dkfgbg/edit?toc_node_uuid=pmiEJWm-hM78-F-u)
- 这是 LangChain 推荐的管道式写法，我们一步步拆解：


- - **输入层**：
  - `RunnablePassthrough()`：透传用户输入的问题（`input_text = "怎么减肥？"`）
  - `retriever | format_func`：先调用检索器获取相关文档，再用 `format_func` 格式化上下文
  - 最终给 Prompt 传入一个字典：`{"input": "怎么减肥？", "context": "[减肥就是要少吃多练, 在减脂期间吃东西很重要...]"}`
  - **Prompt 层**：把问题和上下文填充到预设模板（图中未展示，通常类似「基于以下资料回答：{context}\n 问题：{input}」）
  - **模型层**：调用大模型（如通义千问、GPT）生成回答
  - **解析层**：`StrOutputParser()` 把模型输出的消息对象转成纯字符串

#### 调用链并获取结果

```
chain.invoke(input_text)
```

- 传入用户问题，触发整个链的执行：


- - 检索 → 2. 格式化 → 3. 填充 Prompt → 4. 模型生成 → 5. 解析输出


- 最终返回模型基于检索资料生成的减肥建议

### 三、关键细节与优化建议

1. **检索数量控制**：`k=2` 表示每次只取最相关的 2 条资料，避免上下文过长
2. **格式化问题**：当前 `format_func` 拼接成 `[内容1内容2]`，不是标准 JSON 格式，更推荐改成：

```
def format_func(docs: list[Document]):if not docs:return "无相关参考资料"return "\n".join([doc.page_content for doc in docs])
```

1.  或者用 `json.dumps()` 生成标准数组格式
2. **数据持久化**：`InMemoryVectorStore` 重启后数据会丢失，生产环境建议替换为 `FAISS`、`Chroma` 等持久化向量库

### 四、执行流程总结

```
用户提问 → 检索最相关2条资料 → 格式化上下文 → 填充Prompt → 大模型生成 → 输出纯文本回答
```
