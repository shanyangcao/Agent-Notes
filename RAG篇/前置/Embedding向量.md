Embedding 本质是**把文本、图像、音频等非结构化数据，转化为高维数值向量**，让机器能理解和计算数据间的语义关系。

#### 向量定义与向量化的意义

- **向量定义**：一串有序的数字数组（比如 `[0.12, -0.34, 0.56, ...]`），每个维度代表数据的一个抽象语义特征。
- **向量化意义**：


- - 把人类可理解的自然语言 / 多媒体，转成机器可计算的数值形式。
  - 让相似内容在向量空间中距离更近，便于做检索、推荐、聚类等任务。

#### 向量相似度算法

用来衡量两个向量在语义上的接近程度，常见两种：

- **余弦距离（Cosine Similarity）**


- - 核心：计算向量夹角的余弦值，范围 `[-1, 1]`，越接近 1 表示语义越相似。
  - 优点：不受向量长度影响，更适合文本语义相似度计算。


- **欧式距离（L2 Distance）**


- - 核心：计算向量空间中两点的直线距离，距离越小越相似。
  - 优点：直观反映向量在空间中的位置差异，适合需要考虑向量模长的场景。

#### 向量化实践

- **向量模型的 API 调用**


- - 直接调用成熟云服务 / 开源模型的 API（如 OpenAI Embeddings、文心一言向量接口、智谱 Embedding 等），快速生成向量，无需自己训练模型。
  - 适合快速开发、轻量级场景，成本低、部署简单。


- **向量化模型本地部署**


- - 下载开源向量模型（如 BGE、Sentence-BERT 等），在本地环境部署运行。
  - 优点：数据隐私安全、可定制化、无调用次数限制；缺点：需要一定硬件资源和部署成本。
