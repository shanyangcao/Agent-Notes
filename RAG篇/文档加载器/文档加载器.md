##   一、核心概念理解

**Document Loader = 数据接入层(Data Ingestion Layer)**

它的核心职责是:

```
外部数据源 → 读取数据 → 转换为统一的 Document 对象
```

## 二、Document 标准结构

所有加载器最终输出的统一格式:

```
Document(
    page_content="这里是文本内容",
    metadata={"source": "文件路径", "page": 1}
)
```

> 💡 这是 LangChain 的**统一中间格式**,所有下游处理都基于这个结构

### 目录级加载器(Directory Loader)

**用途:** 批量读取整个文件夹

```

)
docs = loader.load()
```

> ✨ 自动递归子目录,支持通配符匹配

## 四、核心方法

所有加载器都支持以下方法:

### 1. `load()` - 同步加载

> 一次性加载全部数据到内存

```
docs = loader.load()
```

**适用场景:** 小型数据集

### 2. `lazy_load()` - 惰性加载

> 返回生成器,按需加载数据

```
for doc in loader.lazy_load():
    print(doc.page_content)
```

**适用场景:** 大文件处理,节省内存

### 3. `aload()` - 异步加载

```
docs = await loader.aload()
​```

**适用场景:** 异步编程环境

## 五、标准处理流程

LangChain 的经典数据处理 Pipeline:
​```
Loader → Document → Splitter → Embedding → Vector Store → Retriever → LLM
```

### 完整示例代码:

```
from langchain.document_loaders import PyPDFLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter

# 步骤1: 加载文档
loader = PyPDFLoader("document.pdf")
docs = loader.load()

# 步骤2: 文本切分
splitter = RecursiveCharacterTextSplitter(
    chunk_size=500,        # 每块大小
    chunk_overlap=50       # 块之间重叠字符数
)
chunks = splitter.split_documents(docs)

# 步骤3: 后续可接入向量化、检索等
```

## 六、PyPDFLoader 详解

### 核心特性:

✅ 基于 PyPDF 库 ✅ **按页解析** PDF 文档 ✅ 自动生成页码 metadata

### 示例代码:

```
from langchain.document_loaders import PyPDFLoader

loader = PyPDFLoader("report.pdf")
docs = loader.load()

# 查看第一页的元数据
print(docs[0].metadata)
# 输出: {'source': 'report.pdf', 'page': 0}

# 查看第一页的内容
print(docs[0].page_content)
```

### 输出结构:

```
[
    Document(
        page_content="第1页的文本内容...",
        metadata={'source': 'report.pdf', 'page': 0}
    ),
    Document(
        page_content="第2页的文本内容...",
        metadata={'source': 'report.pdf', 'page': 1}
    ),
    # ...
]
```

## 八、最佳实践

1. **大文件处理** → 优先使用 `lazy_load()`
2. **批量加载** → 使用 `DirectoryLoader` + glob 模式
3. **元数据管理** → 充分利用 `metadata` 字段做溯源
4. **错误处理** → 加载器可能抛出异常,建议 try-except 包裹

```
try:
    docs = loader.load()
except Exception as e:
    print(f"加载失败: {e}")
```

> 💡 **核心理念:** Document Loader 是 LangChain 的数据入口,所有外部数据都需要先转换为统一的 Document 格式,才能进入后续的处理流程。
