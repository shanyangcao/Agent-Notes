### 一、核心理念：从 “被动响应” 到 “主动代理”

传统 LLM 应用（如早期 ChatGPT）是 **被动式** 的：你问，它答。而 **Agentic AI（智能体 AI）** 是 **主动式** 的：它有目标、能感知、会规划、可行动、能记忆、可学习。**Agentic Design Patterns** 就是实现这种 “主动性” 的**架构蓝图**。

### 二、四大核心模式

书中系统总结了 **21 种模式**，以下是最核心、最常用的 4 种：

#### 1. 反思模式 (Reflection)

**原理**：智能体生成答案后，**自己当评委**，检查、批判、修正自己的输出，形成闭环。

- **作用**：大幅减少幻觉（Hallucination）、提升准确性、逻辑更严谨。
- **例子**：写代码 → 自我审查漏洞 → 重写优化；写文章 → 自查事实错误 → 修正。![img](https://cdn.nlark.com/yuque/0/2026/png/56763514/1776271343685-621a275d-d8f9-4e22-b682-bd03acdb6f4b.png)

#### 2. 工具使用模式 (Tool Use)

**原理**：智能体不局限于自身知识库，**主动调用外部工具**获取信息或执行动作。

- **工具类型**：搜索引擎（实时信息）、数据库、代码解释器、API、文件系统。
- **例子**：“查今天天气” → 调用天气 API；“计算复利” → 调用 Python 代码。![img](https://cdn.nlark.com/yuque/0/2026/png/56763514/1776271343844-fcb9588f-ff4c-4de6-b306-94dc208f6a38.png)

#### 3. 规划模式 (Planning)

**原理**：将**复杂大任务**自动拆解为**多个子步骤**，按序执行，并根据反馈动态调整路径。

- **作用**：处理长链条、多步骤的复杂任务（如旅行规划、软件开发）。
- **例子**：“帮我策划一场北京 3 日游” → 分解为：查景点 → 订酒店 → 规划路线 → 预订门票。![img](https://cdn.nlark.com/yuque/0/2026/png/56763514/1776271343923-e0c929c9-112d-4bcf-8c6c-1aac8867de80.png)

#### 4. 多智能体协作模式 (Multi-Agent)

**原理**：多个**专业化**智能体分工合作，模拟人类团队工作。

- **常见形式**：


- - **主管 - 工人**：一个 Manager Agent 分配任务给多个 Worker Agent。
  - **专家团队**：CEO、程序员、设计师、测试员共同开发软件（如 ChatDev）。


- **优势**：专业的人做专业的事，复杂任务效率与质量双高。![img](https://cdn.nlark.com/yuque/0/2026/png/56763514/1776271344119-74e899bc-a5f1-4bc5-839c-553c31087b84.png)

### 三、完整模式体系

整套模式分为四大层级，覆盖从基础控制到高级安全的全流程：

1. **构建与控制层**：提示链 (Prompt Chaining)、路由 (Routing)、并行化 (Parallelization)
2. **认知与执行层**：反思 (Reflection)、工具使用 (Tool Use)、规划 (Planning)、记忆管理 (Memory)
3. **协作与适应层**：多智能体 (Multi-Agent)、学习与适应 (Learning)、知识检索 (RAG)
4. **安全与治理层**：护栏 (Guardrails)、异常处理、人机协作 (Human-in-the-Loop)

### 四、与传统软件设计模式的区别

- **传统模式**（如单例、工厂）：解决**确定性**逻辑问题。
- **Agentic 模式**：解决**非确定性、推理、决策、动态交互**问题，核心是**让 AI 自主控制流程**。

### 五、应用价值

- **可靠性**：通过反思、护栏等模式减少 AI 幻觉与错误。
- **能力边界**：通过工具、RAG 突破模型本身知识限制。
- **复杂度管理**：通过规划、多 Agent 分解复杂任务。
- **工程化**：提供标准化方案，让 AI 系统开发更像传统软件工程，可复用、可维护。

总而言之，**Agentic Design Patterns** 是当前 AI 从 “生成式” 迈向 “自主智能体” 时代的**核心工程方法论**。掌握这些模式，是构建下一代可靠、强大、自主 AI 应用的关键。
