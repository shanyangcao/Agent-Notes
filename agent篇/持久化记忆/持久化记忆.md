# 一、持久化记忆到底要存什么？

1. **短期记忆（会话历史）**：本轮对话的 messages
2. **长期记忆（用户记忆）**：用户偏好、习惯、重要信息
3. **工作记忆（Agent 执行轨迹）**：工具调用、思考步骤、中间结果
4. **索引记忆（向量记忆）**：把历史对话向量化，用于召回

# 二、通用实现思路

1. 选择存储介质
   1. 关系型：MySQL / PostgreSQL
   2. 键值：Redis
   3. 向量：Chroma / FAISS / PGVector / Milvus
2. 定义记忆结构
   1. 会话 ID（session_id）
   2. 用户 ID（user_id）
   3. 消息内容、角色、时间、元信息
3. 实现读写接口
   1. 加载记忆：Agent 启动时加载
   2. 保存记忆：每轮对话结束后保存
4. 构建记忆召回策略
   1. 最近 k 条
   2. 摘要记忆
   3. 向量检索记忆

# 三、LangChain 官方标准实现

1. ## 使用 `ChatMessageHistory` + 外部存储

LangChain 自带多种持久化后端：

- `FileChatMessageHistory`（文件）
- `RedisChatMessageHistory`（Redis）
- `SQLiteChatMessageHistory`
- `PostgresChatMessageHistory`

示例（Redis 持久化）：

```
from langchain_community.chat_message_histories import RedisChatMessageHistory
from langchain_core.chat_history import BaseChatMessageHistory

def get_history(session_id: str) -> BaseChatMessageHistory:
    return RedisChatMessageHistory(
        session_id=session_id,
        url="redis://localhost:6379/0"
    )
```

## 配合 `RunnableWithMessageHistory` 实现带记忆的 Agent

```
from langchain_core.runnables.history import RunnableWithMessageHistory

agent_with_memory = RunnableWithMessageHistory(
    runnable=agent,
    get_session_history=get_history,
    input_messages_key="input",
    history_messages_key="chat_history",)
```

**效果**：同一个 session_id，对话历史会自动持久化、自动加载。

# 四、LangGraph 持久化

LangGraph 天生支持**状态持久化**，这是它做 Agent 最强的地方。

## 核心：把 State 存到外部

LangGraph 支持：

- `MemorySaver`（内存，不持久）
- `RedisSaver`
- `SqliteSaver`
- `PostgresSaver`

## 一行开启 Redis 持久化

```
from langgraph.checkpoint.redis import RedisSaver

checkpointer = RedisSaver.from_url("redis://localhost:6379")

graph = builder.compile(checkpointer=checkpointer)
```
