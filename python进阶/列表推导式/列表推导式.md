列表推导式（List Comprehension）是 Python 中一种**简洁、高效创建列表**的语法糖，核心是把「循环 + 条件判断 + 元素处理」浓缩成一行代码，比传统的 `for` 循环更简洁，执行效率也更高。

#### 1. 基本语法

```
# 基础格式：[要添加的元素 for 临时变量 in 可迭代对象]
new_list = [expression for item in iterable]

# 带条件过滤的格式：[要添加的元素 for 临时变量 in 可迭代对象 if 条件]
new_list = [expression for item in iterable if condition]
```

- `expression`：对每个 `item` 的处理逻辑（比如计算、转换、直接取值）
- `item`：遍历可迭代对象时的临时变量
- `iterable`：可以遍历的对象（列表、字符串、字典、range 等）
- `condition`（可选）：过滤条件，只有满足条件的 `item` 才会被处理

#### 2. 直观对比：列表推导式 vs 传统 for 循环

举个最简单的例子：创建一个包含 1~5 平方的列表。

**传统 for 循环写法**（新手易理解，但代码量大）：

```
squares = []  # 先创建空列表
for i in range(1, 6):
    squares.append(i * i)  # 循环添加元素
print(squares)  # 输出：[1, 4, 9, 16, 25]
```

**列表推导式写法**（一行搞定，更简洁）：

```
squares = [i * i for i in range(1, 6)]
print(squares)  # 输出：[1, 4, 9, 16, 25]
```

#### 3. 带条件过滤的例子

需求：筛选出 1~10 中的偶数，再计算平方。

```
# 列表推导式
even_squares = [i * i for i in range(1, 11) if i % 2 == 0]
print(even_squares)  # 输出：[4, 16, 36, 64, 100]

# 等价的 for 循环
even_squares = []
for i in range(1, 11):
    if i % 2 == 0:
        even_squares.append(i * i)
```

#### 4. 更实用的场景

「把消息对象列表转字典列表」：

```
# 假设 message_to_dict 是把消息对象转字典的函数
new_messages = [message_to_dict(msg) for msg in all_messages]

# 等价于
new_messages = []
for msg in all_messages:
    new_messages.append(message_to_dict(msg))
```
