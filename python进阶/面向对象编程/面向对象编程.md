## 一、面向对象编程核心概念

### 1.1 什么是面向对象编程

面向对象编程（Object-Oriented Programming, OOP）是一种程序设计范式，它将数据和操作数据的方法封装在一起，形成"对象"。这种编程方式更贴近人类认知世界的方式，使代码更易理解、维护和扩展。

**核心思想**：

- 将现实世界的事物抽象为程序中的对象
- 对象之间通过消息传递进行交互
- 通过继承和多态实现代码复用和灵活性

## 二、面向对象三大特性

### 2.1 封装

**定义**：将数据（属性）和操作数据的方法（行为）封装在一个类中，并隐藏内部实现细节。

**优点**：

- 保护数据安全，防止外部随意修改
- 降低代码耦合度
- 提高代码可维护性

**实现方式**：

```
class BankAccount:
    def __init__(self, balance):
        self.__balance = balance  # 私有属性，外部无法直接访问
    
    def deposit(self, amount):
        """存款"""
        if amount > 0:
            self.__balance += amount
            return True
        return False
    
    def get_balance(self):
        """获取余额"""
        return self.__balance

# 使用
account = BankAccount(1000)
account.deposit(500)
print(account.get_balance())  # 1500
# print(account.__balance)  # 报错，无法直接访问私有属性
```

### 2.2 继承

**定义**：子类可以继承父类的属性和方法，实现代码复用。

**优点**：

- 减少代码重复
- 建立类之间的层次关系
- 提高代码可扩展性

**类型**：

1. **单继承**：一个子类只继承一个父类
2. **多继承**：一个子类继承多个父类（Python支持，Java不支持）
3. **多层继承**：形成继承链

**示例**：

```
# 父类
class Animal:
    def __init__(self, name):
        self.name = name
    
    def speak(self):
        pass

# 子类继承父类
class Dog(Animal):
    def speak(self):
        return f"{self.name} says Woof!"

class Cat(Animal):
    def speak(self):
        return f"{self.name} says Meow!"

# 使用
dog = Dog("Buddy")
cat = Cat("Whiskers")
print(dog.speak())  # Buddy says Woof!
print(cat.speak())  # Whiskers says Meow!
```

### 2.3 多态

**定义**：同一个方法调用可以产生不同的行为，具体行为取决于对象的实际类型。

**优点**：

- 提高代码灵活性
- 降低代码耦合
- 便于扩展新功能

**实现方式**：

```
class Shape:
    def area(self):
        pass

class Circle(Shape):
    def __init__(self, radius):
        self.radius = radius
    
    def area(self):
        return 3.14 * self.radius ** 2

class Rectangle(Shape):
    def __init__(self, width, height):
        self.width = width
        self.height = height
    
    def area(self):
        return self.width * self.height

# 多态的体现
def print_area(shape):
    print(f"Area: {shape.area()}")

circle = Circle(5)
rectangle = Rectangle(4, 6)

print_area(circle)     # Area: 78.5
print_area(rectangle)  # Area: 24
```

## 三、面向对象其他重要特性

### 3.1 抽象

**定义**：隐藏复杂的实现细节，只暴露必要的接口。

**实现**：

```
from abc import ABC, abstractmethod

class Vehicle(ABC):
    @abstractmethod
    def start_engine(self):
        pass
    
    @abstractmethod
    def stop_engine(self):
        pass

class Car(Vehicle):
    def start_engine(self):
        return "Car engine started"
    
    def stop_engine(self):
        return "Car engine stopped"
```

### 3.2 接口与抽象类

| 特性       | 抽象类                   | 接口                     |
| ---------- | ------------------------ | ------------------------ |
| **定义**   | 含有抽象方法的类         | 完全抽象的类（Java）     |
| **实例化** | 不能实例化               | 不能实例化               |
| **方法**   | 可以有具体方法和抽象方法 | 只有抽象方法（Java 8前） |
| **继承**   | 单继承                   | 多实现                   |
| **用途**   | 定义通用行为             | 定义规范/契约            |

## 四、获取对象信息

### 4.1 使用 type() 函数

**作用**：获取对象的类型

```
print(type(123))        # <class 'int'>
print(type('hello'))    # <class 'str'>
print(type([1, 2, 3]))  # <class 'list'>

class Dog:
    pass

d = Dog()
print(type(d))  # <class '__main__.Dog'>
```

### 4.2 使用 isinstance() 函数

**作用**：判断对象是否是某个类的实例（包括父类）

```
class Animal:
    pass

class Dog(Animal):
    pass

d = Dog()
print(isinstance(d, Dog))     # True
print(isinstance(d, Animal))  # True（子类实例也是父类实例）
print(isinstance(d, object))  # True（所有类都继承自object）

# type() vs isinstance()
print(type(d) == Dog)     # True
print(type(d) == Animal)  # False（type不考虑继承关系）
```

### 4.3 使用 dir() 函数

**作用**：获取对象的所有属性和方法

```
class Person:
    def __init__(self, name):
        self.name = name
    
    def say_hello(self):
        return f"Hello, I'm {self.name}"

p = Person("Alice")
print(dir(p))
# 输出：['__class__', '__delattr__', ..., 'name', 'say_hello', ...]

# 过滤魔法方法，只看自定义属性
attrs = [attr for attr in dir(p) if not attr.startswith('_')]
print(attrs)  # ['name', 'say_hello']
```

## 五、类的特殊方法（魔法方法）

### 5.1 `__str__()` 方法

**作用**：定义对象的字符串表示（用于print和str）

```
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    def __str__(self):
        return f"Person(name={self.name}, age={self.age})"

p = Person("Bob", 25)
print(p)  # Person(name=Bob, age=25)
```

### 5.2 `__iter__()` 和 `__next__()` 方法

**作用**：使对象可迭代

```
class Countdown:
    def __init__(self, start):
        self.current = start
    
    def __iter__(self):
        return self
    
    def __next__(self):
        if self.current <= 0:
            raise StopIteration
        self.current -= 1
        return self.current + 1

# 使用
for num in Countdown(5):
    print(num)  # 5, 4, 3, 2, 1
```

### 5.3 `__getitem__()` 方法

**作用**：支持索引访问和切片

```
class MyList:
    def __init__(self, data):
        self.data = data
    
    def __getitem__(self, index):
        return self.data[index]
    
    def __len__(self):
        return len(self.data)

ml = MyList([10, 20, 30, 40])
print(ml[0])      # 10
print(ml[1:3])    # [20, 30]
print(len(ml))    # 4
```

### 5.4 `__getattr__()` 方法

**作用**：动态返回属性（属性不存在时调用）

```
class DynamicObject:
    def __init__(self):
        self.name = "Dynamic"
    
    def __getattr__(self, attr):
        return f"Attribute '{attr}' not found"

obj = DynamicObject()
print(obj.name)      # Dynamic
print(obj.age)       # Attribute 'age' not found
print(obj.anything)  # Attribute 'anything' not found
```

### 5.5 `__call__()` 方法

**作用**：使对象可以像函数一样被调用

```
class Multiplier:
    def __init__(self, factor):
        self.factor = factor
    
    def __call__(self, x):
        return x * self.factor

double = Multiplier(2)
triple = Multiplier(3)

print(double(5))  # 10
print(triple(5))  # 15
```

## 六、类属性 vs 实例属性

### 6.1 实例属性

```
class Person:
    def __init__(self, name):
        self.name = name  # 实例属性

p1 = Person("Alice")
p2 = Person("Bob")
print(p1.name)  # Alice
print(p2.name)  # Bob
```

### 6.2 类属性

```
class Person:
    species = "Human"  # 类属性，所有实例共享
    
    def __init__(self, name):
        self.name = name

p1 = Person("Alice")
p2 = Person("Bob")

print(p1.species)  # Human
print(p2.species)  # Human

Person.species = "Homo Sapiens"
print(p1.species)  # Homo Sapiens（所有实例都改变）
print(p2.species)  # Homo Sapiens
```

## 七、类方法和静态方法

### 7.1 实例方法

```
class Calculator:
    def add(self, a, b):  # 第一个参数是self
        return a + b
```

### 7.2 类方法

```
class Person:
    count = 0
    
    def __init__(self, name):
        self.name = name
        Person.count += 1
    
    @classmethod
    def get_count(cls):  # 第一个参数是cls（类本身）
        return cls.count

p1 = Person("Alice")
p2 = Person("Bob")
print(Person.get_count())  # 2
```

### 7.3 静态方法

```
class MathUtils:
    @staticmethod
    def add(a, b):  # 没有self或cls参数
        return a + b
    
    @staticmethod
    def is_even(n):
        return n % 2 == 0

print(MathUtils.add(5, 3))     # 8
print(MathUtils.is_even(10))   # True
```

## 八、属性装饰器

### 8.1 使用 @property

```
class Circle:
    def __init__(self, radius):
        self._radius = radius
    
    @property
    def radius(self):
        """获取半径"""
        return self._radius
    
    @radius.setter
    def radius(self, value):
        """设置半径"""
        if value < 0:
            raise ValueError("Radius cannot be negative")
        self._radius = value
    
    @property
    def area(self):
        """计算面积（只读属性）"""
        return 3.14 * self._radius ** 2

# 使用
c = Circle(5)
print(c.radius)  # 5（调用getter）
c.radius = 10    # 调用setter
print(c.area)    # 314.0（只读，无法赋值）
```

## 九、常见设计模式

### 9.1 单例模式

```
class Singleton:
    _instance = None
    
    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

s1 = Singleton()
s2 = Singleton()
print(s1 is s2)  # True（同一个实例）
```

### 9.2 工厂模式

```
class Dog:
    def speak(self):
        return "Woof!"

class Cat:
    def speak(self):
        return "Meow!"

class AnimalFactory:
    @staticmethod
    def create_animal(animal_type):
        if animal_type == "dog":
            return Dog()
        elif animal_type == "cat":
            return Cat()

animal = AnimalFactory.create_animal("dog")
print(animal.speak())  # Woof!
```

## 十、最佳实践

### 10.1 命名规范

- 类名：大驼峰（PascalCase）- `MyClass`
- 方法/属性：小写下划线（snake_case）- `my_method`
- 私有属性：双下划线前缀 - `__private_attr`

### 10.2 组合优于继承

- 优先使用组合（has-a）而非继承（is-a）

### 10.3 避免过度设计

- 不要为了OOP而OOP，保持简单

### 10.4 使用类型提示

```
class Person:
    def __init__(self, name: str, age: int):
        self.name: str = name
        self.age: int = age
    
    def greet(self) -> str:
        return f"Hello, I'm {self.name}"
```
